# PRD — 축구 전술 분석 프로그램

## 1. 제품 개요

**제품명**: Football Tactics & Data Analysis System (FTDAS)
**플랫폼**: 웹앱 (브라우저)
**배포**: Vercel (GitHub push 자동 배포)
**디자인**: 토트넘 컬러 (네이비 + 화이트)

---

## 2. 화면 구성

탭 2개:
- **탭 1**: 전술 보드
- **탭 2**: 데이터 분석

---

## 3. 기능 상세

### 탭 1 — 전술 보드

#### 3.1 피치
- 축구장 상단 뷰 (녹색 잔디 + 라인)
- 양팀 하프 구분

#### 3.2 선수 마커
- 원형 마커
- 마커 안에 번호 (1~11) + 포지션 약자 (GK, CB, CM, ST 등) 표시
- 드래그앤드롭으로 피치 위 자유 배치
- 선수 추가 / 삭제 버튼

#### 3.3 포메이션 프리셋
- 선택 시 마커 자동 배치
- 지원 포메이션: 4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2

#### 3.4 움직임 화살표
- 마커에서 드래그해 화살표 그리기
- 전술 이동 경로 표시용
- 화살표 삭제 가능

---

### 탭 2 — 데이터 분석

#### 3.5 손흥민 개인 스탯
- 시즌 골 / 어시스트 / 출전 경기 수
- API-Football 자동 연동 + 수동 입력 병행

#### 3.6 리그 순위표
- 지원 리그: EPL / 라리가 / 분데스리가 / 세리에A / K리그 / MLS
- 드롭다운 또는 탭으로 리그 전환
- 현재 시즌 팀 순위 (승점, 승/무/패)
- API-Football 자동 연동 + 하루 1회 캐싱 (무료 플랜 100콜 절약)

#### 3.7 경기 일정 / 결과
- 토트넘 다음 경기 일정
- 최근 경기 결과 (스코어)
- API-Football 자동 연동

---

## 4. 기술 스택

| 항목 | 선택 |
|------|------|
| 프레임워크 | Vanilla JS 또는 React (슈퍼천재 선택) |
| 피치 렌더링 | HTML Canvas 또는 SVG |
| 데이터 API | API-Football (무료 플랜, 하루 100콜) |
| 배포 | Vercel |
| 저장소 | GitHub |

## 5. 스코프 외 (Out of Scope)

- 영상 분석 / 클립 업로드
- 전술 보드 저장/불러오기 (1차 버전 제외)
- 멀티플레이어 / 공유 기능
- 모바일 앱

---

## 6. 개발 순서 (제안)

1. 피치 + 선수 마커 드래그앤드롭
2. 포메이션 프리셋
3. 화살표 그리기
4. 탭 UI + 토트넘 디자인
5. API-Football 연동 (손흥민 스탯)
6. 6개 리그 순위 + 경기 일정
7. Vercel 배포
